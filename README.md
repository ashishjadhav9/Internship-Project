# Internship-Project

**Real-Time Sign Language Translator**

📌 Project Overview

The Real-Time Sign Language Translator is an intelligent application designed to improve communication between hearing-impaired individuals and others.
The system uses computer vision and machine learning to detect hand gestures, translate them into text, convert text into sign animations, and detect user emotions.

The application provides an interactive interface where users can select one of the three available modules.

🎯 **Objectives**

Enable real-time translation of sign language to text

Convert text input into sign language representation

Detect human emotions using facial expressions

Provide an easy-to-use unified application interface

🧩 **Project Modules**


1️⃣ Sign to Text

This module detects hand gestures through a webcam and translates them into readable text.

Features

Real-time hand tracking

Gesture recognition using computer vision

Instant translation of signs into text output

Technologies Used

OpenCV

MediaPipe

TensorFlow

NumPy

-----------------------------------------------------------------------------------

2️⃣ Text to Sign

This module converts typed text into sign language representation.

Features

User enters text

System converts text into corresponding sign gestures

Helps non-sign language users communicate with deaf individuals

Technologies Used

Python

OpenCV

Custom gesture datasets

----------------------------------------------------------------------------------------

3️⃣ Emotion Detection

This module analyzes facial expressions using the webcam and detects emotions.

Features

Real-time face detection

Emotion classification

Displays detected emotion on screen

Technologies Used

DeepFace

OpenCV

Machine Learning



🖥 **Application Workflow**

User runs the main program.

The Application Home Page opens.

The interface displays three modules:

Sign to Text

Text to Sign

Emotion Detection

The user selects the desired module.

The selected module starts and performs its function.
